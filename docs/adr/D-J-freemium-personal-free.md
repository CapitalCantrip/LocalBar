# ADR D-J — Personal use is free; commercial use is licensed

**Status:** Accepted  
**Date:** 2026-09-14  
**Deciders:** Jay

Everything a solo power user needs stays free. Commercial organisations pay a licence fee. The primary personal-use revenue mechanism is voluntary donations.

**Why gate on org use, not features:** The alternative — restricting advanced features (profiles, multi-instance, CLI) to paid tiers — would push the most engaged personal users to competitors or forks, destroying the community that makes the product worth licensing. The value proposition for org licensing is org-scale features (fleet management, team profile sync, usage analytics), not feature restriction.

**Why not freemium with a feature wall:** Power users — the people most likely to advocate for LocalBar inside an org — are exactly the people who would hit a feature wall. Keeping everything free for personal use turns power users into evangelists rather than detractors.

**Consequence:** The exact boundary between personal-free and commercial-licensed features will evolve. The governing principle is stable: individual value stays free, org-scale value is licensed.
